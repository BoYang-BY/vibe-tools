# 🌿 Life Garden｜命運之種

**一場由選擇編織的奇幻森林旅程。**

![Life Garden 封面](assets/cover.png)

> 每一個選擇，都會留下生長的痕跡。

Life Garden｜命運之種是一款結合**奇幻劇情、植物養成與人格測驗概念**的網頁互動遊戲。

玩家將帶著一顆神祕的種子進入森林，透過十幕故事中的不同選擇，逐漸影響植物的成長方向。旅程結束後，種子將進化成八種命運植物之一，並根據玩家的選擇產生專屬的旅人特質分析。

本作品使用 **Vibe Coding** 的方式開發，透過 ChatGPT 協助程式實作，並經由多次測試、修改與版本迭代，逐步完善遊戲內容與使用者體驗。

## ✨ 遊戲特色

### 🌱 1. 植物養成與動態成長

玩家可以替種子命名、選擇花盆，並隨著故事推進觀察植物逐步成長。

植物使用 SVG 繪製，從種子、萌芽到最終綻放，搭配動畫呈現不同的生長階段。

### 📖 2. 十幕奇幻森林冒險

故事包含森林岔路、受傷的螢火蟲、星光商人、月光湖與神祕大門等事件。

部分選擇會影響後續劇情，例如：

* 第二幕的決定會影響第七幕的相遇事件。
* 第三幕獲得的寶物可以在第八幕使用。
* 第六幕包含隨機天氣事件，增加遊玩變化。

### 🌸 3. 八種命運植物進化

系統會依據玩家在旅程中累積的四項特質，決定最終植物：

**冒險、沉靜、溫暖、想像**

八種植物分別為：

| 命運植物   | 對應特質    |
| ------ | ------- |
| ☀️ 太陽花 | 冒險      |
| 🌙 月光蕨 | 沉靜      |
| 💗 暖心藤 | 溫暖      |
| ✨ 星願草  | 想像      |
| 🌅 晨昏花 | 冒險 × 沉靜 |
| 🌳 暖陽樹 | 冒險 × 溫暖 |
| 🪻 夢境蘭 | 沉靜 × 想像 |
| 🌠 星語藤 | 溫暖 × 想像 |

### 🔮 4. 專屬旅人特質分析

完成十幕故事後，除了揭曉植物品種，系統還會顯示：

* 專屬旅人稱號
* 四項特質分布
* 玩家在故事中實際做過的選擇
* 植物介紹與森林寄語

**注意：** 特質分析屬於遊戲化的趣味結果，並非正式心理學人格測驗。

### 📚 5. 植物圖鑑與收藏

玩家可以解鎖不同植物，查看植物介紹，並保存已完成的旅程紀錄。

重新開始遊戲不會清除原本的圖鑑收藏，鼓勵玩家探索不同的選擇與結局。

### 🎵 6. 森林背景音樂

V8.2 使用 Web Audio API 即時合成背景音樂，包含主旋律、低音及和弦伴奏。

系統預設嘗試播放音樂，若受到瀏覽器自動播放政策限制，則會在玩家首次互動後嘗試啟動。玩家也可以自行開關音樂及調整音量。

## 🤖 AI 輔助開發與版本迭代

本作品並非一次由 AI 生成完成，而是透過 **「提出需求 → AI 實作 → 實際測試 → 發現問題 → 再次修改」** 的流程持續完善。

| 版本      | 發現的問題                   | 修改與改善                 |
| ------- | ----------------------- | --------------------- |
| V1      | 希望建立可互動的植物養成網頁          | 完成每日生活紀錄、經驗值與植物成長功能   |
| V1.1～V4 | 介面及成長機制仍需改善             | 持續調整操作、視覺設計與養成體驗      |
| V5      | 每日打卡需要多天才能看到成果，不適合短時間展示 | 重新設計為奇幻森林劇情選擇遊戲       |
| V6      | 故事較短，選項之間缺少關聯           | 擴充十幕故事，加入分支、道具與隨機事件   |
| V7      | 結局只有植物名稱，缺少選擇結果的解釋      | 增加八種植物、人格分析與圖鑑收藏      |
| V7.1    | 電腦版植物與右側分析結果未對齊         | 調整結局頁面排版              |
| V8      | 核心玩法完整，但遊戲細節與氛圍仍可提升     | 加入森林光點、動畫、章節進度及圖鑑介紹   |
| V8.1    | 遊戲缺少背景音樂                | 加入 Web Audio API 音樂系統 |
| V8.2    | 音樂音量較小，且需要手動開啟          | 優化預設播放、提高音量並豐富旋律      |

### 主要設計轉折：從生活紀錄到奇幻冒險

最初的 Life Garden 是以每日睡眠、喝水、運動及心情紀錄來培養植物。然而在實際測試後，發現玩家必須累積多天的紀錄才能看到明顯成長，不適合短時間體驗。

因此，重新與 AI 討論玩法，將作品改為可以在一次遊玩中完成的奇幻森林冒險，同時保留植物養成的核心概念。

後續再根據遊玩過程中發現的問題，持續增加劇情關聯、植物進化、人格分析及視聽細節。

這次開發讓我體會到，**AI 能協助快速完成程式，但作品的方向、修改需求與使用者體驗，仍然需要透過實際測試與判斷來決定。**

## 🌿 開發心得

這次 Vibe Coding 作業最大的收穫，是學會如何透過 AI 反覆修改與完善作品。

從最初的植物養成，到重新設計成劇情冒險，再到最後調整人格分析、植物位置及背景音樂，每一次修改都是在實際操作後，找出可以改善的地方。

我認為 Vibe Coding 不只是讓 AI 幫忙寫程式，更重要的是能否清楚描述需求、判斷生成結果是否符合預期，並持續調整作品，直到達到自己想要的效果。
